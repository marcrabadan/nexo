Nexo Backend

Build services with typed routes, persistent data and model-powered workflows using Nexo’s existing language and libraries.

Start with a working API · Add a database

Build one useful endpoint

  1. Define a route and its request types. Start with the local server example and test valid and invalid requests.
  2. Connect the route to stored data. Use typed queries and transactions for changes that must succeed together.
  3. Add authentication and roles. Authorize each protected operation on the backend.
  4. Declare and check permissions. Verify that access outside the intended grant is denied.

Add what your application needs

nexo.db
Database connections, queries, transactions and migrations.
AI and agents
Model calls, typed answers and registered tools. Keep provider credentials on the server and bound agent usage.
Streams and concurrency
Process events and coordinate work when a single request is no longer enough.
Privacy and reliability
Control personal data and make retries, failure handling and recovery explicit.

Connect the browser and deploy

Nexo Web builds the browser interface; its typed data APIs call your backend through same-origin requests. Browser components and server routes use separate compilation and runtime paths.

Use Nexo DevOps for infrastructure and delivery, and Nexo Shield for execution boundaries. The local server examples demonstrate supported behavior; production hosting, TLS, session security and operational readiness need their own validation.
