# Site fonts

Self-hosted, unmodified Latin subsets downloaded on 2026-10-27. The site
does not contact a font service at runtime. Both families use the SIL Open
Font License 1.1; the original licenses accompany the binaries.

| File | Family and style | Exact binary source |
| --- | --- | --- |
| `manrope-latin-variable.woff2` | Manrope, normal, variable weights 400–800 | https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2 |
| `ibm-plex-mono-latin-regular.woff2` | IBM Plex Mono, normal, weight 400 | https://fonts.gstatic.com/s/ibmplexmono/v20/-F63fjptAgt5VM-kVkqdyU8n1i8q1w.woff2 |

The Latin URLs and supported weights were obtained from Google Fonts CSS:

- https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&display=swap
- https://fonts.googleapis.com/css2?family=IBM+Plex+Mono&display=swap

Original license sources:

- `Manrope-OFL.txt`: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- `IBMPlexMono-OFL.txt`: https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt
