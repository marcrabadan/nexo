Practical reference

Find the failing boundary

Start with the command, runtime and first diagnostic. Fix one concrete failure before changing the architecture.

For a reproducible starting point, run the support inbox walkthrough. Check the runtime map when behavior differs between targets.

Installation and toolchain

nexo is missing or imports fail
From the repository root, activate source .venv/bin/activate and rerun python -m pip install -e .. Use Python 3.12 or newer. Verify the interpreter belongs to the environment you installed into.
Native compilation cannot find its compiler or linker
Follow the native build instructions for the supported Rust/LLVM toolchain and host. Use the interpreter for supported development work while resolving the toolchain; that does not validate the native target.
Vite is unavailable
For repository examples, run npm ci --prefix nexo/web_tools. Use the Node version required by the development guide. Ordinary browser builds and checks do not require Node; release optimization does.

Permissions and isolation

A read, secret or network operation is denied
Run python -m nexo security check app.nexo to inspect declared policy. Compare the exact path, environment variable or hostname with the intended grant. A Shield denial is fatal; catching an ordinary error cannot grant permission. Check dependency and request ceilings as well as root policy.
Effect analysis reports an unknown
Unknown means the static analyzer cannot establish the effect. Inspect the dynamic operation and relevant authorization; do not treat unknown as safe or solve it with a broad grant.
The Linux worker probe fails
Run nexo security probe on the actual host and inspect missing kernel features. The offline profile denies sockets and threads. Select a compatible documented profile rather than expecting it to run a networked backend unchanged.

Browser requests and authentication

The page is blank when opened as a file
Serve the build over HTTP. ES modules do not reliably load through file: URLs. Confirm you are serving the build directory, not the source folder.
NW3001 or a response validation error
Declare as: T and compare the actual JSON shape with that contract. Missing or extra fields, incompatible scalars and unsafe wire integers can invalidate a response. Read data only inside a ready or mutation success branch.
A browser API URL is rejected
Use a same-origin absolute path such as /api/tickets. Cross-origin URLs, redirects and custom headers are unsupported. Use HTTPS outside loopback development.
A write fails with a CSRF error
Open the application through the session-serving backend or gateway. It must inject the CSRF meta token and validate Origin and token on writes. The static preview server cannot create that session. Do not remove CSRF checks to make a request pass.
The API returns 401 or 403
401 usually means authentication is missing or invalid; 403 can indicate a missing role or failed CSRF check. Inspect the backend response and session adapter. Browser visibility and UI state do not authorize a backend operation.
The walkthrough cannot start
Check that ports 8765 and 8081 are free and use a dedicated writable --state directory. Read the first backend diagnostic. Use a new state directory to distinguish old SQLite rows from a new run.

Read the API contracts and options.

AI and token budgets

The walkthrough always returns the same summary
That is expected: the local fixture returns a fixed sentence and synthetic usage. It does not contact a model. Follow the walkthrough’s production steps before integrating a real provider.
A provider call fails
Check the configured provider, model, endpoint, secret and network grant. Keep credentials on the server. A successful stub test does not validate a live model identifier, provider account or price configuration.
An agent exhausts its tokens or steps
Inspect prompt history, reported usage and tool/model turns. Invocation token limits include input and output; an output cap alone is different. Reduce unnecessary context or adjust an intentional allowance. Cancellation and budget failure do not roll back completed external effects or provider charges.

Deployment and delivery

A generated CI file does not run
Export only writes configuration. Review the file, install dependencies, set the working directory and configure runner credentials and approvals before enabling it.
Infrastructure commands fail after local validation
Validate credentials, region, provider permissions and adapter support on the target. A local plan or emulator result does not establish live cloud readiness.
Static hosting loads the UI but API calls fail
Serve the authenticated API through the same origin with the required session and CSRF integration. Static assets alone do not provide a backend, TLS termination, login or persistent storage.

Choose a delivery guide. If a failure remains, prepare the exact command, runtime/version, first diagnostic and a minimal reproducible example. Remove credentials and personal data before sharing logs.
