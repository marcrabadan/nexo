Before you begin

A file, a command, a result.

You will need a text editor and a terminal. Follow the installation instructions, then open a terminal in the Nexo repository folder. Save each example in that folder using the filename shown above its code.

Run the command shown beneath the example. Nexo reads the file and prints its result in your terminal. These pages show the expected output so you can compare yours.

How to use these lessons

Read the example, run it, then change it. Try each exercise before opening its solution. You can also download the example files.

Lesson 1Text and printing

Hello, Nexo.

Your task: greet someone by name.

hello.nexo
name = "Ada"
print("Hello, {name}!")
Output
Hello, Ada!

First install Nexo if you haven’t already. Save the code as hello.nexo, then run:

From your Nexo checkout
.venv/bin/nexo hello.nexo
Download hello.nexo

Read the code

  1. name = "Ada" gives the text "Ada" a name. Double quotes mark text.
  2. print(...) displays a value in the terminal.
  3. Inside text, {name} inserts the value of name. The result is Hello, Ada!.

Your turn

Make the greeting yours

Change the name to "Sam". Add a second print that displays "Your invoice is ready." on its own line.

Show one solution
hello-exercise.nexo
name = "Sam"

Lesson 2Names and exact money

An invoice, one step at a time.

Your task: calculate the total for three items, including VAT.

money.nexo
price = 19.90 EUR
quantity = 3
subtotal = price * quantity
vat = subtotal * 21%

print("Subtotal: {subtotal}")
print("VAT: {vat}")
print("Total: {subtotal + vat}")
Output
Subtotal: 59.70 EUR
VAT: 12.54 EUR
Total: 72.24 EUR

Save the code as money.nexo, then run:

From your Nexo checkout
.venv/bin/nexo money.nexo
Download money.nexo

Read the calculation

  1. price and quantity name the inputs. A name lets you use a value without repeating it.
  2. 19.90 EUR is a money value: an exact decimal amount together with its currency. Nexo keeps the currency in the result.
  3. * means multiply. price * quantity calculates the subtotal; 21% expresses the VAT rate directly.
  4. subtotal + vat adds the two money amounts. You can put this calculation inside {...} to print it.

A name stays bound to its value by default. To work with a value that changes while a program runs, use var. This invoice does not need it.

Your turn

Change the order

Set quantity to 2 and run the program again. Keep the same price and VAT rate. What do you expect the new total to be?

Show one solution
money-exercise.nexo
price = 19.90 EUR
quantity = 2
subtotal = price * quantity
vat = subtotal * 21%

print("Subtotal: {subtotal}")
print("VAT: {vat}")
print("Total: {subtotal + vat}")
Output
Subtotal: 39.80 EUR
VAT: 8.36 EUR
Total: 48.16 EUR

The total is 48.16 EUR. Only the quantity changed; the rest of the calculation uses its new value.

Name the inputs to a calculation, use money and percentages, and print a useful result.

Lesson 3Functions

Write it once.
Use it again.

Your task: calculate two invoices without copying the same calculation.

functions.nexo
fn invoice_total(price, quantity):
    subtotal = price * quantity
    vat = subtotal * 21%
    return subtotal + vat

print(invoice_total(19.90 EUR, 3))
print(invoice_total(49.90 EUR, 2))
Output
72.24 EUR
120.76 EUR

Save the code as functions.nexo, then run:

From your Nexo checkout
.venv/bin/nexo functions.nexo
Download functions.nexo

Give the calculation a name

  1. fn invoice_total(price, quantity): defines a function: a named piece of code you can reuse. price and quantity are the inputs it receives.
  2. The four spaces before each calculation put that line inside the function. A colon starts the block; indentation shows what belongs to it.
  3. return sends the calculated value back to the place that called the function.
  4. invoice_total(19.90 EUR, 3) calls the function with a price and a quantity. print displays the returned result. The second call uses the same code with different inputs.

Your turn

Reuse just the VAT calculation

Write a function named add_vat with one input, amount. Return that amount plus 21% VAT. Call it with the subtotal 19.90 EUR * 3 and print the result.

Show one solution
functions-exercise.nexo
fn add_vat(amount):
    return amount + amount * 21%

subtotal = 19.90 EUR * 3
print(add_vat(subtotal))
Output
72.24 EUR

This smaller function works with any subtotal in the same currency. It does not need to know the item price or quantity.

Download the solution
You can now

Write a function, give it inputs, return a result and reuse it. Your invoice calculator is ready for more than one order.
