Nexo DevOps

Describe infrastructure, automate delivery steps and inspect runtime behavior with Nexo’s deployment libraries and tools.

Start with infrastructure and CI · Deploy a browser application

From a local check to a deployment

  1. Validate the application. Run the relevant checks and tests before preparing infrastructure.
  2. Describe resources. Use nexo.infra declarations and stage settings, then inspect a plan before applying changes.
  3. Define delivery steps. Run a local pipeline and export a reviewable workflow for your CI service.
  4. Configure the target. Supply credentials, permissions and approval settings for your own environment.
  5. Verify the result. Check health, access boundaries and recovery behavior on the actual deployment host.

Validate the environment you will operate

Generating a CI file does not enable the workflow or deploy an application. Infrastructure adapters and local examples do not establish live cloud readiness, availability targets or disaster recovery. Review generated changes, protect credentials and validate the selected provider and host.

Continue with Nexo Backend for service logic, Nexo Shield for permissions and isolation, or the library reference for runnable examples.
