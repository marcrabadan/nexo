Getting Started

Meet Nexo.

Nexo is a readable, statically typed programming language that combines imperative code with declarative constructs for APIs, AI workflows, infrastructure and security policies.

Run code with the Python interpreter or compile it to native code with Rust and LLVM. Start with a small program, then add the libraries and execution boundaries your application needs.

A language you can follow

Nexo uses indentation, named values and functions to keep programs readable. Exact decimal money, typed records and pipelines help express application logic. Functions that can fail return explicit errors: handle them or pass them to the caller with ?.

Security by design

Describe the access your program needs in a policy. Inspect known effects before running it, then choose enforcement appropriate to the workload.

  1. Declare permissions

    Grant specific resources and deny unnecessary capabilities. Static effect analysis highlights known needs and leaves dynamic access marked unknown.

  2. Enforce access

    Nexo Shield checks protected operations and restricts dependency permissions. Policy checks govern supported APIs; they do not confine arbitrary native code.

  3. Isolate execution

    Add a hardened container or the optional Linux worker. Kernel isolation requires supported host features; the offline worker denies sockets and child processes.

Install & run

Your first program,
on your computer.

Use a macOS or Linux terminal with Git and Python 3.12 installed. You’ll download Nexo and run the interpreter, which reads and executes your code.

Using VS Code? Install the Nexo extension for syntax highlighting, diagnostics, formatting and code navigation. Install the Nexo CLI separately and set the extension’s nexo.path setting to its executable.

1. Set up Nexo

Download the source and install it in a virtual environment: a separate place for this project’s Python packages.

Terminal
git clone https://github.com/marcrabadan/nexo.git
cd nexo
python3.12 -m venv .venv
.venv/bin/pip install -e .

Keep this terminal open in the nexo folder for the next steps.

2. Save your first file

In your text editor, create hello.nexo inside the nexo folder and paste these two lines.

hello.nexo
name = "Ada"
print("Hello, {name}!")

3. Run it

Back in the terminal, enter this command.

Terminal
.venv/bin/nexo hello.nexo
Output
Hello, Ada!
