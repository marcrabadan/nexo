Install & run

Your first program,
on your computer.

Use a macOS or Linux terminal with Git and Python 3.12 installed. You’ll download Nexo and run the interpreter, which reads and executes your code.

1. Set up Nexo

Download the source and install it in a virtual environment: a separate place for this project’s Python packages.

Terminal
git clone https://github.com/marcrabadan/nexo.git
cd nexo
python3.12 -m venv .venv
.venv/bin/pip install -e .

Keep this terminal open in the nexo folder for the next steps.

2. Save your first file

In your text editor, create hello.nexo inside the nexo folder and paste these two lines.

hello.nexo
name = "Ada"
print("Hello, {name}!")

3. Run it

Back in the terminal, enter this command.

Terminal
.venv/bin/nexo hello.nexo
Output
Hello, Ada!
Now learn what each line does

When you need explicit permissions

Meet Nexo Shield.

Declare which files and resources a program may access. Shield enforces those permissions and supports native execution inside hardened Docker.

Learn how Shield works
policy.nexo
policy:
    allow read "input.txt"
    deny shell

The program may read input.txt. Shell commands are denied. Learn the language first, then explore how to control access.
