The playground runs the Nexo interpreter (phase 0) on Python compiled to WebAssembly, Pyodide. That runtime, about 10 MB, is downloaded from cdn.jsdelivr.net the first time you open this page. This is the only page of the site that loads files from another site. Your program stays in your browser. Files exist only while it runs, and the examples' data/ folder is there for them to read. Programs that need threads, the network or other processes need Nexo on your machine: install it.
