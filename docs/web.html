Build your first component

Install Nexo using Getting Started, then activate its Python environment with source .venv/bin/activate. Run these commands from the repository root.

Terminal
python -m nexo web check --json examples/web/counter.nexo
python -m nexo web build examples/web/counter.nexo -o /tmp/nexo-counter
python -m http.server 8765 --bind 127.0.0.1 --directory /tmp/nexo-counter

Open http://127.0.0.1:8765/. The button updates the count. This ordinary build requires no Node installation.

One component, from state to screen

state stores the count, fn changes it, view renders it and style keeps its CSS local. Each mounted Counter has its own state.

counter.nexo
use nexo.web

pub component Counter:
    state count: int = 0

    fn increment():
        count += 1

    view:
        main:
            h1("Nexo Web")
            p("Count: {count}")
            button("+", on_click: increment)

    style:
        main {
            padding: 24px;
        }

Choose the right runtime

Browser components compile through the Python CLI. The Rust driver does not compile them. Server routes use the separate nexo.web library; the browser calls that backend through same-origin APIs.

Nexo Web is experimental. SSR, hydration and static generation are not implemented. Keep credentials on the server and enforce authentication and authorization there. See the supported features and deployment boundaries.
