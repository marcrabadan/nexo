Runtime reference

Choose the right execution path

Availability depends on the runtime, host and execution profile. Use this map to find the relevant guide; check exact signatures and restrictions before deployment.

“Supported” means an implementation exists. It does not certify every dependency, platform or production workload.

Read the boundary that affects your task

  • CLI and native compilation — toolchain requirements and commands.
  • Nexo Web limits — experimental browser features, release builds and hosting.
  • Library guides — provider, database and connector prerequisites.
  • Shield execution profiles — permissions, offline isolation and unsupported integrations.
  • Versioned AI context — detailed implemented, experimental, planned and unverified claims.

The WASI build --target web path is separate from Nexo Web components. A browser playground result does not prove native or standalone WASI compatibility. Test the actual runtime and deployment target.
